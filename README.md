## 介绍 / Introduction

「今日新闻」是一款基于 **Python + QML** 的 Class Widgets 2 插件，可在桌面小组件上阅览当日**国内**、**国际**与**体育**新闻，数据来自新浪新闻官方接口（feed.mix.sina.com.cn），无需密钥。
